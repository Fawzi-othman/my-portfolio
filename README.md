# Cybersecurity & Networking — Project Portfolio

A collection of hands-on technical projects demonstrating practical experience in enterprise networking, security monitoring, and Windows infrastructure.

---

## Project Showcase

### 01. Enterprise Network Infrastructure & Firewall

**Domain:** Network Engineering & Security

Cisco Packet Tracer implementation featuring:

- VLAN segmentation and inter-VLAN routing
- DHCP and network addressing
- Cisco ASA firewall configuration
- NAT/PAT and Access Control Lists
- ISP routing and simulated Internet connectivity

**Repository:** [Network Infrastructure Lab](https://github.com/fawzi-othman/network-infrastructure-lab)

---

### 02. Splunk SIEM — Windows Security Monitoring

**Domain:** Security Operations & Monitoring

Windows-based SIEM lab demonstrating:

- Splunk Enterprise deployment
- Windows Security Event collection
- Universal Forwarder configuration
- Authentication log investigation
- SPL searches and event analysis
- SOC monitoring dashboard

**Repository:** [Splunk Authentication Monitoring](https://github.com/fawzi-othman/splunk-authentication-monitoring)

---

### 03. Active Directory & Windows Security

**Domain:** Windows Infrastructure & Security Administration

Windows Server 2022 and Windows 11 domain lab covering:

- Active Directory Domain Services
- DNS and domain integration
- Organizational Units and user management
- Group Policy configuration
- Advanced Security Auditing
- Windows Defender Firewall
- Workstation security hardening

**Repository:** [Active Directory Lab](https://github.com/fawzi-othman/active-directory-lab)
